# Changelog

All notable changes to this repository will be documented in this file.

This project follows a practical versioning style while the packages are in early development:

- patch versions for fixes and documentation improvements
- minor versions for new backward-compatible APIs
- major versions for breaking changes

## 0.1.0 - 2026-05-25

### Added

- Created the Open Source Lab monorepo.
- Added `@osl/event-forge`, a workflow DAG runner with retries, timeouts, cancellation, and lifecycle hooks.
- Added `@osl/flagship`, a deterministic feature flag evaluator with segment rules and weighted rollouts.
- Added `@osl/loglens`, a log parsing and anomaly detection toolkit with a streaming CLI.
- Added CI, contribution guidance, security policy, and bilingual repository README.
