# Code of Conduct

Open Source Lab is a small technical community space. We ask contributors to keep discussions respectful, focused, and welcoming.

## Expected Behavior

- Be considerate and constructive.
- Assume good intent when reviewing issues or pull requests.
- Give feedback on code, behavior, and documentation rather than on people.
- Make space for first-time contributors to ask questions.

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory language or exclusionary behavior.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.

## Enforcement

Project maintainers may edit, hide, or remove comments and may restrict participation when behavior harms the project or its contributors.

If you need to report a concern, please open a private security-style report or contact the repository owner through GitHub.
