# Contributing

Thanks for helping improve Open Source Lab.

## Workflow

1. Create a focused branch.
2. Add or update tests for behavioral changes.
3. Run `npm test`.
4. Keep public APIs small and documented.

## Code Style

- Use ESM modules.
- Prefer pure functions.
- Avoid dependencies unless they remove substantial complexity.
- Keep error messages actionable.

## Pull Requests

Please include:

- what changed
- why it changed
- how it was tested
- any compatibility concerns
